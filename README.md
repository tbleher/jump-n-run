# Ein (unfertiges) 2D Jump-and-Run Spiel in Godot

Basierend auf dem wunderbaren [YouTube-Tutorial von Brackey](https://www.youtube.com/watch?v=LOhfqjmasi0)
und dem [Code dazu](https://github.com/Brackeys/first-game-in-godot).

Die Grafiken sind fast alle unter CC0 (Public Domain).

Sie sind aus dem ursprünglichen Repo von Brackey (oben verlinkt) sowie von:
- https://opengameart.org/content/16x16-animated-campfire
- https://opengameart.org/content/toxic-barreldrip-animation
- https://opengameart.org/content/bushly-and-princess-sera
- https://opengameart.org/content/life-heart-and-rainbow-star-gifs

Zusätzlich werden Icons von
https://www.softicons.com/toolbar-icons/16x16-free-application-icons-by-aha-soft
verwendet. Diese sind unter CC BY-SA-3.

Der Fokus im Godot-Setup ist, dass Kinder leicht neue Level erstellen können.

Work in Progress (kein fertiges Spiel).
